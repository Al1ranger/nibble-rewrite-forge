# Architecture and review boundary

**Client:** chooses an exact original program and signs registration/optimization; displays results. It cannot provide the authoritative rewrite, cost or equivalence verdict.

**Contract:** owns the bounded machine, original program, native creator and nonce bindings, AI synthesis call, independent complete-domain artifact verification, publication root and reusable root-bound evaluation.

**External world:** not represented. No claim of observations, delivery, inventory, truth, authority, elapsed time or confidence. The complete formal program is the full evidence for equivalence; no hidden observer URL or caller summary is treated as observed reality.

## Different representative mechanism

| Earlier mechanism | Maintained state and result | This build |
|---|---|---|
| Owner-controlled graph proposals | Mutable graph/head and accepted transitions | No graph or administrator; immutable formal input and synthesized executable program |
| SemanticFlowEnvelope | Source-derived pair compatibility and capacity/min-cut bounds | No source matching or allocation; AI constructs code, validators prove total finite equivalence and cost improvement |
| BoundedPolicyCompiler / SourceTariffVM | Natural-language interpretation compiled into executable rules/prices | Input is already a complete formal function; only a cheaper equivalent implementation may be published |
| AffineInvariantForge | AI-generated inductive proof witnesses for safety of transition systems | AI-generated executable rewrite; exhaustive two-input bitvector equivalence, not inductive safety or a graph transition |
| Certificate/capability variants | Verdict, intended principal and one-time consumption | No execution permission minted; published computation can be evaluated repeatedly by anyone |

The classical synthesis/verification pattern is attributed, not globally novel by assertion. This is one formal rewrite primitive, not multiple renamed domain variants.

## Equivalence protocol

Leader receives the full original program plus exact operation semantics and costs. It calls the LLM to produce a program-only JSON object, parses and exhaustively verifies it. Each validator independently parses the leader's exact candidate, executes the original and candidate on all 256 pairs, and reconstructs every proof field. Canonical whole-report equality is required against that independent reconstruction.

There is no second AI candidate: uniqueness of program syntax is neither required nor meaningful for an open-ended synthesis problem. Independent formal verification is the substantive check, not trusting a leader-provided label or only validating output schema. Two syntactically different equivalent improving artifacts can each be valid.

The deterministic caller repeats all checks after consensus, verifies unchanged job context, and stores the artifact. No storage writes occur in nondeterministic flow. Native creator authorization and expected input root are checked before synthesis. Failed candidates do not create artifacts; published artifacts cannot be overwritten.

## Exact claim

For every x,y in 0–15, execute(original,x,y)=execute(rewrite,x,y), with mask 15 after every intermediate operation, and declared_cost(rewrite)<declared_cost(original). Grammar, length and stack checks are required independently. A semantic hash is a commitment after full evaluation, not a replacement for comparison.

No statement is made for wider words, signed integers, native gas or optimality across all programs. Consumers must bind the original input root and machine policy; the returned artifact root identifies which implementation was selected. Evaluations have no consumption counter or authority side effect.
